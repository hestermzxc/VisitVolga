# Сверка афиши

Программа сравнивает афишу сайта (выгрузку из Битрикса) с сайтами-источниками. На выходе отчёт и CSV-файлы для импорта.

## Запуск

1. Выгрузите афишу из Битрикса: Экспорт CSV, разделитель `;`. Положите файл рядом и укажите путь в `config.xml` → `<export>`.
2. Дважды щёлкните `run.bat` или выполните `python afisha_sync.py`.
3. Результат появится в папке `sverka_ГГГГ-ММ-ДД` (её расположение задаётся в `<output>`).

Нужен Python 3. Для ручного запуска установите зависимости командой `python -m pip install openpyxl beautifulsoup4`. При запуске через `run.bat` зависимости устанавливаются автоматически.

## Как добавить сайт с афишей

В `config.xml` внутри `<sources>` добавьте строку:

```xml
<source url="https://ссылка-на-афишу/" name="Как подписать в отчёте"/>
```

Если это официальный сайт одной площадки, укажите её код и пометьте источник как главный:

```xml
<source url="https://rusdram21.ru/afisha/" venue="N9yWUgtr" official="true"/>
```

Программа умеет читать:

| Тип | Что это |
|---|---|
| `afisha21` | afisha21.ru: анонсы и театральная афиша по месяцам |
| `rusdram21` | официальная афиша Русского драмтеатра |
| `teatr21`, `chuvdram`, `puppet21`, `maiteatr`, `radario` | Камерный театр, Чувашский драмтеатр, Театр кукол, МАЙтеатр и Станиславский.com |
| `jsonld` | любая страница с разметкой schema.org Event (многие билетные сервисы и сайты театров) |

Тип определяется по адресу, указывать его не обязательно. Официальные данные имеют приоритет для совпавших названия, даты и площадки. Остальные показы сохраняются в сверке.

## Цены на билетные сеансы

Для Чувашского драмтеатра цены подтверждаются по [официальному фиду Ticketland](https://affiliates.ticketland.ru/page110248566.html). Программа сопоставляет площадку, название, дату и время сеанса. Если в афише Театра кукол цена отсутствует, она проверяется на странице этого сеанса в Quick Tickets. Фид Ticketland загружается потоком один раз за сверку, поэтому на медленном соединении обработка может занять несколько минут.

Подтверждённая цена попадает в CSV. Если билетный источник недоступен или сеанс не подтверждён, в отчёте появится причина, а цена существующей карточки сохранится.

## Что лежит в результатах

| Файл | Что делать |
|---|---|
| `afisha_sverka.xlsx` | отчёт; жёлтые строки нужно проверить |
| `import_updates_now.csv` | импортировать сразу |
| `fix_xml_id.php` | один раз запустить в «Командной PHP-строке», сначала с `$dryRun = true` |
| `import_updates_after_fix.csv` | импортировать после `fix_xml_id.php` |
| `import_new_events.csv` | новые события, сразу активны |

При импорте в параметре «Что делать с элементами, отсутствующими в файле» всегда выбирайте **«ничего не делать»**.

## Предпросмотр в браузере

Скачайте [visitvolga-preview.html](../visitvolga-preview.html) кнопкой **Download raw file** и откройте его локально. Добавьте `import_new_events.csv` для просмотра карточек и `afisha_sverka.xlsx` из той же сверки для жёлтой подсветки. Карточки можно редактировать и пропускать. После загрузки CSV кнопка **«Скачать CSV»** сохраняет правки и выгружает оставшиеся строки. Подробные шаги описаны в [инструкции](ИНСТРУКЦИЯ.md#локальный-предпросмотр-афиши).

## Когда что-то не так

- **«Площадка не распознана»:** добавьте площадку в `<venues>`: как она написана в анонсе (`pattern`) и либо код из списка «Где» (`code`), либо текст с адресом (`place`).
- **Источник ошибся** (неверное время или цена): добавьте в `<decisions>` строку `<reject>`, чтобы правка не применялась, или `<force>`, чтобы задать верное значение.
